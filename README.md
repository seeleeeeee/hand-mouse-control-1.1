# управление мышью жестами рук

простой проект, который позволяет управлять курсором компьютера с помощью жестов через веб-камеру

## что умеет

- управление курсором указательным пальцем
- клик левой кнопкой при сведении большого и указательного пальцев
- показывает все 21 точку на руке
- плавное движение курсора

## что использовал

- python 3.10
- opencv - для работы с камерой
- mediapipe - от гугла, распознает руки
- ctypes - управление мышью на windows

## как запустить

```bash
# скачай проект
git clone https://github.com/твой-ник/hand-mouse-control
cd hand-mouse-control

# создай виртуальное окружение
python -m venv venv

# активируй (windows)
venv\Scripts\activate

# установи библиотеки
pip install opencv-python mediapipe

# запусти
python main.py
